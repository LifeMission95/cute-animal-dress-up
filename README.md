# 모찌와 친구들의 작은 옷장

귀여운 아기토끼 모찌, 아기치타 치치, 아기펭귄 포포에게 코디 세트를 입혀 주는 어린이용 웹게임입니다.

## 실행

별도 설치 없이 `index.html`을 브라우저에서 열어도 실행됩니다. 로컬 서버로 실행하려면:

```bash
python3 -m http.server 4173
```

그다음 브라우저에서 `http://localhost:4173`을 여세요.

## 기능

- 토끼 모찌, 치타 치치, 펭귄 포포 3종 캐릭터 선택
- 옷장에 들어가기 전 캐릭터를 고르고, 옷장 안의 발바닥 버튼으로 다시 선택 가능
- 모자·상의·하의·신발을 각각 자유롭게 선택하는 옷장
- 각 카테고리에 같은 순서와 테마 라벨로 배치된 8가지 코디 조합
- 별과 초승달 무늬가 선명한 `별빛` 잠옷 아이템
- 카드 미리보기와 실제 착용 결과가 동일한 SVG 원본을 공유해 모양과 색상이 일치
- 옷 카드를 한 번 누르면 바로 입혀지는 어린이용 터치 조작
- 화면 상단의 큰 새로고침 버튼으로 웹게임 즉시 새로고침
- 캐릭터 몸 → 여유 있는 옷 → 얼굴 순서의 레이어링과 넓어진 클리핑으로 자연스러운 어깨 핏
- 깜짝 변신 / 다시 시작
- 옷을 입을 때 캐릭터 애니메이션과 반짝이 효과
- 켜고 끌 수 있는 짧은 효과음
- 선택한 캐릭터·모자·상의·하의·신발·소리 설정을 브라우저 `localStorage`에만 저장 (DB 및 서버 의존성 없음)
- 10~11인치 iPad 가로모드에 맞춘 한 화면 레이아웃
- iPad Safari의 주소창 높이가 달라져도 `100dvh` 안에서 고정되어 페이지 스크롤 없음
- 글을 읽기 어려운 아이를 위해 실제 옷 아이콘과 한 단어 중심으로 구성
- 키보드 및 모바일 화면 지원
